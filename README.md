# Satellite-Derived Bathymetry – Port Phillip Bay

This repository contains supplementary results and figures from my RMIT capstone research investigating the feasibility of Satellite-Derived Bathymetry (SDB) across the shallow sand shoals of the Great Sands in southern Port Phillip Bay.

The study used Sentinel-2 and PlanetScope SuperDove imagery, calibrated using NASA's ICESat-2 ATL24 photons and the Stumpf log-ratio model.

### Supplementary Results and Figures

The results are organised into three acquisition epochs:

- **Epoch 1 (2021):** Sentinel-2
- **Epoch 2 (2023):** Sentinel-2 and PlanetScope SuperDove
- **Epoch 3 (2024):** Sentinel-2 and PlanetScope SuperDove

Each folder contains the available calibration, internal validation and SDB raster figures across the different depth ranges.
